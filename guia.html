01 / ESTRUTURA E SIGNIFICADO

HTML organiza o conteúdo.

As tags descrevem o papel de cada parte da página. Use um título principal, mantenha uma hierarquia de títulos e escolha elementos de acordo com seu significado.

<!doctype html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Meu projeto</title>
  <link rel="stylesheet" href="style.css">
  <script src="script.js" defer></script>
</head>
<body>
  <header>
    <h1>Meu projeto</h1>
    <nav aria-label="Menu principal">
      <a href="#sobre">Sobre</a>
    </nav>
  </header>
  <main>
    <section id="sobre">
      <h2>Sobre o projeto</h2>
      <p>Uma ideia que vale compartilhar.</p>
    </section>
  </main>
  <footer>Criado para aprender.</footer>
</body>
</html>

Detalhes que fazem diferença

  • Use <a> para navegar e <button> para executar uma ação.
  • Inclua um alt adequado nas imagens. Para uma imagem puramente decorativa, use alt="".
  • Associe cada campo a um <label>.
  • Use caminhos relativos, como imagens/capa.jpg, para o projeto funcionar em uma subpasta.

02 / APARÊNCIA E LAYOUT

CSS transforma a apresentação.

Uma regra CSS combina um seletor com propriedades e valores. Comece com uma boa base e adicione estilos aos poucos.

* { box-sizing: border-box; }

body {
  margin: 0;
  font-family: system-ui, sans-serif;
  line-height: 1.6;
  color: #20382d;
  background: #fafbf7;
}

main {
  width: min(100% - 2rem, 70rem);
  margin-inline: auto;
}

img { max-width: 100%; height: auto; }

.grade { display: grid; gap: 1.5rem; }

@media (min-width: 48rem) {
  .grade { grid-template-columns: repeat(3, 1fr); }
}

a:focus-visible, button:focus-visible {
  outline: 3px solid #5d7e35;
  outline-offset: 4px;
}

Flexbox ou Grid?

Flexbox ajuda a distribuir elementos em uma direção, como os links de um menu. Grid é útil para organizar linhas e colunas, como uma galeria de cartões. A escolha depende do layout que você quer construir.

03 / EVENTOS E COMPORTAMENTO

JavaScript responde às ações.

Selecione elementos do HTML, escute um evento e atualize a página. O atributo defer no script permite acessar o HTML depois de ele ser lido pelo navegador.

<button type="button" id="botao">Testar interação</button>
<p id="mensagem" aria-live="polite">Clique para começar.</p>
const botao = document.querySelector('#botao');
const mensagem = document.querySelector('#mensagem');
let cliques = 0;

botao.addEventListener('click', () => {
  cliques += 1;
  mensagem.textContent = `Você clicou ${cliques} vez(es).`;
});

Use textContent quando quiser alterar apenas texto. Ele não interpreta o conteúdo como HTML.

04 / ANTES DE COMPARTILHAR

Teste uma coisa de cada vez.

  1. Abra index.html no navegador e confira se os arquivos foram carregados.
  2. Teste todos os links, botões e filtros.
  3. Diminua a janela para verificar o layout de celular.
  4. Use Tab, Shift + Tab e Enter para conferir a navegação pelo teclado.
  5. Abra as ferramentas do navegador e confira o console.
  6. Depois de publicar, repita os testes no endereço público.

Publicação no GitHub Pages

Envie os arquivos para um repositório seu. Em Settings → Pages, escolha Deploy from a branch, selecione main e /(root), e salve. O arquivo index.html deve estar nessa pasta. Confira as opções atuais na documentação oficial do GitHub.

05 / QUANDO ALGO NÃO FUNCIONA

Comece por estas verificações.

Meu CSS não aparece. O que confiro?

Compare o nome e o caminho do arquivo com o valor de href no link do HTML. Confira letras maiúsculas e minúsculas. Abra a aba de rede das ferramentas do navegador e veja se há um erro 404.

Meu botão não faz nada. Por onde começo?

Confira se o script foi carregado, se o seletor encontra o elemento e se o evento foi registrado. Leia a primeira mensagem de erro no console antes de alterar várias partes do código.

A imagem funciona no meu computador, mas não no site.

Verifique se a imagem foi enviada, se a extensão está correta e se o caminho é relativo ao arquivo HTML. Nomes de arquivo com letras maiúsculas e minúsculas diferentes podem falhar na hospedagem.

Como salvo este guia em PDF?

Use o botão “Imprimir / salvar em PDF” no início do guia e escolha a opção de PDF no seu navegador.
